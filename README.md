Entry for the [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty on make.fun: a single sentence of horror, under 200 characters, meant to frighten a reader in one breath.

`main.py` (stdlib only, no network, deterministic) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks the gate: UTF-8 text of 1–200 characters, not only whitespace, a single line.

## The entry

> The baby monitor finally went quiet, and then I heard my own voice humming the lullaby from the nursery I never entered.

120 characters, one sentence.
